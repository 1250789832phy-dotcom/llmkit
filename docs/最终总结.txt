========================================================================
                        🏗️ 架构设计亮点
========================================================================

三层架构:
  ┌─────────────┐
  │   Client    │  业务逻辑层 (重试、错误处理、流式)
  └──────┬──────┘
         │
  ┌──────┴───────┐
  │   Provider   │  适配器层 (统一接口、厂商适配)
  └──────┬───────┘
         │
    ┌────┴────┬──────────┐
    │         │          │
  Mock    OpenAI     Custom

设计模式:
  • 适配器模式 - Provider 统一接口
  • 模板方法 - Client 重试逻辑
  • 策略模式 - 可切换的 Provider

技术特点:
  • 零依赖 - 仅用 Python 标准库
  • 类型安全 - 完整的类型注解
  • 确定性测试 - Mock 提供一致输出
  • 生成器 - 流式输出内存高效
