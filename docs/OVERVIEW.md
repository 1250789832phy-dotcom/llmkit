   MockProvider ──→ 无需 API key
                ──→ 确定性输出
                ──→ 快速迭代

3. 自动重试
   失败 ──→ 等待 0.5s ──→ 重试
   失败 ──→ 等待 1.0s ──→ 重试
   失败 ──→ 等待 2.0s ──→ 重试
   成功 ✓

4. 错误分类
   LLMError
   ├─ NetworkError      (网络问题)
   ├─ ServerError       (服务器错误，可重试)
   ├─ RateLimitError    (限流，可重试)
   ├─ AuthError         (认证错误)
   └─ ConfigError       (配置错误)

5. 类型安全
   @dataclass
   class Message:
       role: str       ← IDE 自动补全
       content: str    ← 类型检查

6. 流式支持
   def stream(...):
       for chunk in ...:
           yield chunk  ← 逐块返回，内存高效
